## Задание 1 [С++ PARALLEL LANG] Создать параллельный язык программирования

Требуется создать язык программирования, в котором будет доступна установка
следующих команд:

- Установка счетного цикла
- Вывод в консоль
- Вывод в файл в режиме добавления
- Арифметические операции +, -, *, /

Счетный цикл должен поддерживать дальнейшую установку всех остальных
поддерживаемых команд.
Для реализации задачи использовать технологию объектно-ориентированного
программирования в части реализации поддерживаемых команд языка.
В программе должны быть отражены следующие шаги:
1.1. Текстовый ввод команд. Каждая новая строка – это новый набор команд.
1.2. Ожидание команды на окончание ввода
1.3. Параллельное исполнение введенных строк (наборов команд). Наборы команд
должны исполняться параллельно. В консоли фиксировать время запуска /
завершения каждого потока. При выводе информации о времени указывать
принадлежность потока к строке (набору команд)

```
lab5/build/run_spl.exe -i <INPUT_FILE_PATH> -o <OUTPUT_FILE_PATH>
```

Аргументы `<OUTPUT_FILE_PATH>` и `<INPUT_FILE_PATH>` - опциональные. По умолчанию ввод и вывод будут производиться через консоль. Если все же задать эти аргументы, то вывод будет сделать в файл, указанный в аргументе в режиме `append`.

- При запуске без аргументов будет ввод и вывод будут производиться через консоль.
- При задании аргумента  `-i <INPUT_FILE_PATH>` ввод будет считываться из файла (вместо `-i` можно использовать флаг `--input`).
- При задании аргумента `-o <OUTPUT_FILE_PATH>` вывод будет делаться в файл в режиме **append** (вместо `-o` можно использовать флаг `--output`)

### Синтаксис языка

Язык называется spl - simple parallel language. Функционала не так много, но основые правила следующие:

1. Каждая строчка исполняется отдельным потоком. На всякий случай максимальное число строк ограничено числом 1000.

2. Каждая команда начинается с символа `!`. А в конце прораммы необходимо оставить строчку только с символом `!` без команд.

3. Язык поддерживает создание переменных 2 типов - `int32` и `float32`:

```
!int a = 6 !int b = -2
!flt c = 0.33 !flt d = -5.4
!
```

4. Язык поддерживает бинарные операции `+, -, *, /` с переменными (и записывает резульлтат в новую или существующую переменную, удаляя предыдущее значение, при этом тип переменной не важен, он тоже перезапишется):

```
!int a = 8 !int b = 1 !expr c = b / a !expr c1 = a + b
!int d = 10 !flt f = 3.3 !expr g = f * d !expr g1 = f - d
!
```

Тип переменной после выражения `!expr` будет определяться из типов входящих операндов по простому правилу - если хоть один из операнодв типа `flt`, то созданная переменная будет типа `flt`.

5. В языке есть опция вывести (в консоль или файл) переменную:

```
!int a = 9 !flt b = 3.45 !print a !print b
!
```

Вывод будет в слудующем формате (здесь использовался 1 поток, т. к. в коде 1 строчка):
```
[THREAD 0] a : 9 (int)
[THREAD 0] b : 3.450000 (flt)
```

6. Язык поддерживает простую реализацию цикла `for`:

```
!for n = 5 !print n
!
```

Все, что идет после объявления цикла будет расцениваться как его тело. Все команды, идущие до цикла, внутрь цикла не попадают. При вызове команды `!for n = 5` создается переменная типа `int`, которая принимает значения от 0 до 5 (не включительно) на каждой итерации цикла.

Вывод такого кода будет:

```
[THREAD 0] n : 0 (int)
[THREAD 0] n : 1 (int)
[THREAD 0] n : 2 (int)
[THREAD 0] n : 3 (int)
[THREAD 0] n : 4 (int)
```

Больше детальных примеров (файлы формата `.spl`) есть в директории: [`lab5/scripts`](../scripts).

### Схема работы программы

1. Исполняемый файл `run_spl` после обработки входных аргументов io хэндлером (где происходит перенаправления входного и выходного потока в файл, если поданы соответствующие аргументы) вызывает парсер языка spl.

2. Парсер токенизирует входные команды по строкам. Отделяет команды друг от друга (удаляя символ `!`). Разбивает команду на составляющие, которые будут понятны рабочему ядру языка.

3. Затем вызывается само ядро, в которое отправляются команды в токенизированном виде. В зависимости от количества заданий (строк) создается пул потоков, которые будут параллельно исполнять эти задания.

4. В рамках потока исполняются заранее разбитые по функциям задания, которые взаимодействуют с 2 существующими сущностями в ядре программы: переменные (Variables) и команды (Comands). Поддерживаются 3 типа команд - создание переменной, вычисление и принт переменной.

5. У всех команд одинаковый интерфейс взаимодействия, т. к. они наследованы от общего базового класса.
